## Deployment

This portfolio is designed for GitHub Pages.

To deploy:

1. Create a GitHub repository for the software engineering portfolio.
2. Add `index.html`, `portfolio-style.css`, and this README.
3. Push the files to the repository's default branch.
4. Open the repository's **Settings → Pages**.
5. Configure deployment from the default branch and root directory.
6. Save the configuration and use the generated GitHub Pages URL.
